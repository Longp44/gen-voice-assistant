# 常见问题

## 部署

**Q: `npm ci` 报错 / 启动失败？**
确认 Node.js 版本为 `^22.22.2 || ^24.15.0`（`node -v`）。项目使用 `node:sqlite`，低于 22.22 不可用。

**Q: 浏览器打开 401？**
需要先配对设备：在服务器执行 `node cli/bin/qwenaudio.mjs gateway pair --name 我的手机 --endpoint <你的地址>`，在手机浏览器打开输出的链接。

**Q: 反代后语音连不上 / 一直转圈？**
检查 nginx 是否带 WebSocket 头（`Upgrade` / `Connection "upgrade"` / `proxy_read_timeout 3600s`），见 `deploy/nginx/gen.conf`。确认 `QWEN_AUDIO_AGENT_ALLOWED_ORIGINS` 包含你的访问来源。

**Q: 会议转写报「缺少 DashScope Key」？**
`runtime/config.env` 里 `QWEN_AUDIO_REALTIME_API_KEY` 未填或未生效；改完需重启服务。

## 使用

**Q: 语音对话能用但「后台执行/主模型任务」不行？**
未安装或未登录 DSH：`npm i -g @deepseek-ai/dsh && dsh login`。此为可选能力。

**Q: 手机收不到通知归档？**
确认已开「通知使用权」、电池白名单；通知归档仅 APK 支持，PWA/浏览器不行。

**Q: 锁屏后录音停了？**
部分国产 ROM 会杀前台服务：把 APK 加入自启动 + 电池白名单，关闭对它的省电策略。

## 成本

**Q: 大概多少钱？**
DashScope 实时语音约 ¥1–3/小时，文件转写约 ¥0.3/小时；DeepSeek 按 token。个人日用通常每月几元～几十元，以各平台账单为准。

## 安全

**Q: 我的数据存在哪？**
全部在你自己的服务器 `runtime/` 目录（SQLite + 文件对象库）。本项目不上传任何数据到第三方，除你主动配置的 DashScope/DeepSeek API 调用。
