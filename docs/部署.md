# 部署指南（Linux 服务器 + systemd + nginx + HTTPS）

以 Ubuntu 24.04、代码位于 `/opt/gen` 为例。

## 1. 安装 Node.js

```bash
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo bash -
sudo apt install -y nodejs
node -v   # 需 ^22.22.2 || ^24.15.0
```

## 2. 安装艮

```bash
sudo mkdir -p /opt/gen && sudo chown $USER:$USER /opt/gen
git clone https://github.com/Longp44/gen-voice-assistant.git /opt/gen
cd /opt/gen
bash scripts/install.sh          # 依赖 + 构建 + 生成 runtime/
vim runtime/config.env           # 填入 DashScope / DeepSeek Key
```

## 3. systemd 服务（自动重启 + 看门狗 + 每日备份）

```bash
sudo cp deploy/systemd/gen-gateway.service /etc/systemd/system/
sudo cp deploy/systemd/gen-watchdog.{service,timer} /etc/systemd/system/
sudo cp deploy/systemd/gen-backup.{service,timer} /etc/systemd/system/
sudo cp deploy/systemd/gen-watchdog.sh /opt/gen/deploy/systemd/  # 确认可执行
sudo chmod +x /opt/gen/deploy/systemd/gen-watchdog.sh /opt/gen/scripts/gen-backup.sh

sudo systemctl daemon-reload
sudo systemctl enable --now gen-gateway
sudo systemctl enable --now gen-watchdog.timer
sudo systemctl enable --now gen-backup.timer
systemctl status gen-gateway
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:3201/   # 期望 200
```

注意按实际修改 `gen-gateway.service` 里的 `User`；备份产物在 `/opt/gen/backups/`，
可另行同步到 S3/COS（把 `scripts/gen-backup.sh` 第二个参数指向挂载点即可）。

## 4. nginx + HTTPS

```bash
sudo apt install -y nginx certbot python3-certbot-nginx
sudo cp deploy/nginx/gen.conf /etc/nginx/sites-available/gen.conf
sudo sed -i 's/your-domain.com/你的域名/g' /etc/nginx/sites-available/gen.conf
sudo ln -s /etc/nginx/sites-available/gen.conf /etc/nginx/sites-enabled/gen.conf
sudo certbot --nginx -d 你的域名     # 自动签发并改写 443 配置
sudo nginx -t && sudo systemctl reload nginx
```

同时把 `runtime/config.env` 里改为：

```bash
GEN_PUBLIC_BASE_URL=https://你的域名
QWEN_AUDIO_AGENT_ALLOWED_ORIGINS=https://你的域名
```

然后 `sudo systemctl restart gen-gateway`。

## 5. 验收

```bash
curl -s -o /dev/null -w '%{http_code}\n' https://你的域名/   # 期望 200
node scripts/gen-acceptance.mjs https://你的域名             # 接口自检
```

浏览器打开 `https://你的域名`，完成设备配对后即可语音对话。验收语音/纪要需真实 Key。
