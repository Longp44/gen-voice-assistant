# 配置说明

## 1. 配置文件位置

- 所有密钥集中在 `runtime/config.env`（由 `config.env.example` 复制而来）
- 网关通过环境变量 `QWAUDIO_CONFIG_DIR` 找到它（`scripts/start.sh`、systemd、Docker 均已配好）

## 2. 环境变量（进程级）

| 变量 | 必需 | 说明 |
|:---|:--:|:---|
| `PORT` | ✅ | 网关端口，默认 3201 |
| `HOST` | ✅ | 监听地址，服务器用 `0.0.0.0` |
| `QWAUDIO_CONFIG_DIR` | ✅ | 配置目录（其下读取 `config.env`） |
| `QWAUDIO_STATE_DIR` | ✅ | 状态目录（会话/日志） |
| `QWAUDIO_DATA_DIR` | ✅ | 数据目录（SQLite DB/对象库/创作） |
| `DSH_HOME` | 建议 | DSH 主模型运行时目录 |
| `QWEN_AUDIO_AGENT_COMPUTER_USE` | 建议 | 设 `false`，禁用电脑操作能力 |
| `QWEN_AUDIO_AGENT_ALLOWED_ORIGINS` | 公网必需 | 允许的浏览器来源，逗号分隔 |
| `GEN_PUBLIC_BASE_URL` | ✅（新增） | 公网地址，用于媒体文件 URL 与 ASR 文件回传 |
| `GEN_TRASH_RETENTION_DAYS` | 可选 | 回收站保留天数，默认 30 |

## 3. config.env 键

| 键 | 说明 |
|:---|:---|
| `QWEN_AUDIO_REALTIME_API_KEY` | 阿里云 DashScope Key（实时语音/ASR/视觉），**必需** |
| `QWEN_AUDIO_REALTIME_MODEL` | 默认 `qwen-audio-3.1-realtime-flash` |
| `QWEN_AUDIO_REALTIME_VOICE` | 默认音色，如 `longanqian` |
| `DEEPSEEK_API_KEY` | DeepSeek Key（主模型/后台/纪要）；不填则这些能力不可用 |
| `GEN_EMAIL_*` | 邮箱 IMAP/SMTP（可选，`GEN_EMAIL_ENABLED=0` 关闭） |

申请入口：DashScope https://bailian.console.aliyun.com/ ；DeepSeek https://platform.deepseek.com/ 。

## 4. DSH（可选）

「后台执行 / 主模型任务」依赖 DeepSeek 官方 CLI：

```bash
npm i -g @deepseek-ai/dsh
dsh login   # 按提示填入 DEEPSEEK_API_KEY
```

不安装 DSH 不影响语音对话、日记、会议转写。

## 5. 数据存储

| 内容 | 位置（`QWAUDIO_DATA_DIR` 下） |
|:---|:---|
| SQLite 数据库 | `data/db/gen.db`（日记、会议、通知、文件索引） |
| 文件对象库 | `data/objects/sha256/<前2位>/<sha256>`（图片/录音/文档） |
| 创作 | `data/creative/<日期>/*.md` |
| 会话 | `state/sessions/`（`QWAUDIO_STATE_DIR` 下） |
| DSH 记忆 | `dsh-home/`（`DSH_HOME` 下） |

备份用 `scripts/gen-backup.sh`（每日轻量 + 每周全量，保留 30 天）。
